# Math for Machine Learning

## Course Structure (8 Weeks)

---

## Week 1: Introduction to Statistics

### Topics

- Populations vs samples
- Sampling techniques
- Mean, median, mode
- Variance and standard deviation
- Covariance and correlation

### Exercises

1. Compute mean, variance, and standard deviation for a dataset.
2. Compare two datasets using covariance and correlation.
3. Identify biased vs unbiased sampling methods.

---

## Week 2: Random Variables & Distributions

### Topics

- Discrete vs continuous random variables
- PMF, PDF, CDF
- Distributions: Normal, Binomial, Uniform, Bernoulli, Poisson
- Central Limit Theorem
- Law of Large Numbers

### Exercises

1. Plot and interpret a normal distribution.
2. Simulate coin tosses and relate to binomial distribution.
3. Demonstrate the Central Limit Theorem using code or examples.

---

## Week 3: Probability Foundations

### Topics

- Conditional probability
- Independence
- Bayes’ theorem
- Joint and marginal distributions

### Exercises

1. Solve conditional probability problems.
2. Apply Bayes’ theorem to a classification example.
3. Compute joint and marginal probabilities from a table.

---

## Week 4: Estimation & Information Theory

### Topics

- Maximum Likelihood Estimation (MLE)
- Maximum A Posteriori (MAP)
- Entropy and cross-entropy
- KL divergence

### Exercises

1. Derive MLE for a Gaussian distribution.
2. Compare MLE vs MAP with examples.
3. Compute entropy for a probability distribution.

---

## Week 5: Linear Algebra Fundamentals

### Topics

- Scalars, vectors, matrices, tensors
- Matrix operations
- Systems of linear equations
- Rank and linear independence

### Exercises

1. Perform matrix multiplication and transpose operations.
2. Solve a system of linear equations.
3. Determine rank and linear independence of vectors.

---

## Week 6: Advanced Linear Algebra

### Topics

- Eigenvalues and eigenvectors
- Orthogonality and projections
- SVD (Singular Value Decomposition)
- PCA (Principal Component Analysis)

### Exercises

1. Compute eigenvalues and eigenvectors of a matrix.
2. Perform dimensionality reduction using PCA.
3. Apply SVD to approximate a matrix.

---

## Week 7: Calculus for Machine Learning

### Topics

- Derivatives and partial derivatives
- Gradients
- Chain rule
- Jacobian and Hessian
- Taylor series

### Exercises

1. Compute gradients of multivariable functions.
2. Apply chain rule to composite functions.
3. Derive Jacobian and Hessian matrices.

---

## Week 8: Optimization & Practical ML Math

### Topics

- Gradient descent (batch, stochastic, mini-batch)
- Convex vs non-convex optimization
- Local/global minima and saddle points
- Regularization (L1, L2)
- Numerical stability (overflow/underflow)

### Exercises

1. Implement gradient descent for a simple function.
2. Compare convergence of different learning rates.
3. Analyze overfitting and apply regularization.

---

## Capstone Exercises (End of Course)

1. Implement linear regression from scratch using gradient descent.
2. Implement logistic regression with cross-entropy loss.
3. Apply PCA to reduce dataset dimensions and visualize results.
4. Derive and implement MLE for a chosen distribution.

---

## Tools and Resources

- Python (NumPy, SciPy)
- Matplotlib for visualization
- Jupyter Notebook

---

## Summary

This course progresses from statistical foundations to optimization techniques used in machine learning. Each week builds toward practical implementation and deeper mathematical understanding.
